Projetos Selecionados & Software Selected Projects & Software

  • AtesN-DS — Resolvedor DNS recursivo de ultra-alta vazão programado em C, eBPF e Go. Processa consultas diretamente na camada de driver de rede via XDP (eBPF maps, Ring Buffer e AF_XDP). +213% de vazão comparado ao hyDNS e redução de até 70ms na latência de cauda. Ultra-high-throughput recursive DNS resolver written in C, eBPF, and Go. Processes queries directly in the network driver layer using XDP (eBPF maps, Ring Buffer, and AF_XDP). +213% throughput vs. hyDNS and up to 70ms tail latency reduction.
  • CurrGen — Engine e pipeline de compilação automatizada de currículos acadêmicos e profissionais. Combina perfis em YAML, renderização em LaTeX de alta precisão tipográfica, cálculo geométrico de densidade e sintonia semântica via LLMs. Automated curriculum compiler and engine combining YAML profiles, pixel-perfect LaTeX typesetting, geometric space budget estimation, and semantic optimization via LLMs.
  • SPIMI Inverted Index Engine — Motor de indexação invertida de alta eficiência com paralelismo multi-core em C++. Implementa arquitetura SPIMI (Single-Pass In-Memory Indexing), compressão de inteiros com V-Byte e ranqueamento de relevância por BM25 e TF-IDF. High-efficiency inverted index engine with multi-core parallelism in C++. Implements SPIMI (Single-Pass In-Memory Indexing), V-Byte integer compression, and BM25/TF-IDF ranked retrieval.
  • ns-3 GPSR Planarization — Extensão do simulador de redes de eventos discretos ns-3 para o protocolo Geographic Perimeter Stateless Routing (GPSR), com suporte a grafos planares dinâmicos (Gabriel Graph e Relative Neighborhood Graph) para recuperação de vazios de roteamento. ns-3 discrete-event network simulator extension for Geographic Perimeter Stateless Routing (GPSR) with dynamic graph planarization (Gabriel Graph and RNG) for void recovery.
  • xv6 RISC-V Kernel Hacking — Modificações no kernel educacional xv6 para arquitetura RISC-V: escalonador proporcional por loteria com alocação determinística de tickets e implementação de nova chamada de sistema (syscall) com rastreamento de contadores. Modifications to the xv6 RISC-V operating system kernel: lottery proportional-share CPU scheduler and custom system calls with process accounting.
  • XDP Network Utilities & HTTP Server — Utilitários de baixo nível executados diretamente no contexto do driver de placa de rede: resposta imediata a ICMP Echo (ping) em nível XDP e servidor HTTP de alta concorrência em C. Low-level networking utilities running directly in the network driver: zero-overhead ICMP Echo (ping) responder in XDP and lightweight concurrent HTTP server in C.
